# Chan's SUDOKU — 패치노트

## v1.3.2 (2026-10-30)

- 휴대폰에서 판이 작게 보이던 문제 수정. 위아래 여백과 버튼 줄 높이를 줄여 아이폰 Safari처럼 주소창이 화면을 많이 차지하는 브라우저에서도 판이 화면 너비를 꽉 채움
- 판은 화면 너비의 90%보다 작아지지 않음. 화면이 아주 작은 휴대폰에서는 살짝 스크롤하면 주소창이 숨으며 전부 보임

## v1.3.1 (2026-10-30)

- 휴대폰에서 스크롤로 주소창이 숨거나 나타날 때, 또는 키보드가 열릴 때 판 크기가 바뀌던 문제 수정. 판 크기는 고정되고, 화면을 돌리거나 창 너비가 바뀔 때만 다시 맞춤

## v1.3.0 (2026-10-30)

- 휴대폰을 가로로 돌리면 판은 왼쪽, 숫자판과 버튼은 오른쪽에 놓여 스크롤 없이 풀 수 있음. 처음 화면도 가로에 맞게 두 칸으로 나뉨
- 태블릿을 세로로 들면 판을 위에 크게, 숫자판을 아래에 놓음
- 화면이 작은 휴대폰에서도 판·도구·숫자판이 한 화면에 들어오도록 판 크기를 자동으로 맞춤
- 아이폰에서 난이도 선택이나 이름·방 코드 입력칸을 누르면 화면이 확대되던 문제 수정
- 버튼을 빠르게 두 번 눌러도 확대되지 않고, 길게 눌러도 글자 선택 메뉴가 뜨지 않음. 화면을 아래로 당겨도 새로고침되지 않음
- 휴대폰 홈 화면에 추가하면 앱처럼 전체 화면으로 열림
- 설정에 화면 켜짐 유지(푸는 동안 화면이 꺼지지 않음)와 진동(틀렸을 때·완성했을 때) 추가. 지원하는 기기에서만 보임
- 휴대폰에서 다시하기 같은 작은 버튼의 누르는 영역을 넓힘

## v1.2.1 (2026-10-27)

- 같이 하기에서 숫자를 빠르게 넣으면 방 연결이 끊겨, 숫자·힌트가 오가지 않고 새로 들어온 사람이 방을 찾지 못하던 문제 수정
- 연결이 끊기면 자동으로 다시 접속하고, 다시 접속하거나 화면으로 돌아오면 놓친 숫자를 받아 옴. 늦게 도착한 판이 다른 사람이 넣은 숫자를 지우지 않음
- 참가자 상태 표시: 자리 비움(다른 탭·앱을 보거나 1분 넘게 입력 없음), 응답 없음(15초 넘게 신호 없음), 연결 끊김(내 연결이 끊겨 다시 연결 중)
- 방 게임 중 방을 나가면 혼자 풀 새 문제로 바뀜. 새로고침 뒤 방에 다시 들어가지 않을 때도 새 문제로 시작
- 방 게임 기록 시간을 완성한 순간 기준으로 정확히 잼
- 방 정보를 받기 전에 내 이름에 방장 표시가 붙던 문제 수정

## v1.2.0 (2026-10-27)

- 처음 화면 추가: 이어 하기, 새 게임(난이도 선택), 같이 하기, 리더보드, 기법, 도움말, 패치노트. 게임 중에는 제목이나 홈 버튼으로 돌아옵니다.
- 도움말과 패치노트 추가
- 이름을 **Chan's SUDOKU**로 변경
- 대전·협동 기록도 리더보드에 등록. 리더보드에서 혼자 · 대전 · 협동을 나눠 봅니다.
  - 대전: 완성한 사람마다 자기 기록이 자동 등록
  - 협동: 방장이 팀 기록(참가자 이름 모두, 팀 힌트·실수 합계)을 한 번 자동 등록
- 같이 하기 창을 열거나 방에서 시작을 기다리는 동안 혼자 풀던 문제의 시간이 멈춤
- 같이 하기 창이 열려 있거나 시작 카운트다운 중에는 새 문제 확인 창처럼 판을 흐리게 가림
- 방 코드 복사는 6자리 코드만 복사
- 방은 마지막 사람이 나갈 때까지 유지되고 같은 코드로 다시 접속 가능. 새로고침해도 다시 들어가며 내 진행 상황이 돌아옵니다. 참가하기에 **최근 방 다시 들어가기** 버튼 추가
- 방 참가자 목록이 들어오고 나가는 대로 바로 바뀜
