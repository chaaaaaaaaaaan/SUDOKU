Chan's SUDOKU

8단계 난이도 · 기법 힌트 · 대전과 협동

·

도움말

규칙

가로줄(행), 세로줄(열), 굵은 선으로 나뉜 3×3 박스마다 1부터 9까지 숫자가 한 번씩만 들어가도록 빈칸을 채웁니다.

입력

  • 칸을 누르고 아래 숫자판이나 키보드 1–9로 숫자를 넣습니다.
  • 메모: 메모 모드를 켜거나(Shift를 한 번 누름) Shift를 누른 채 숫자를 누르면 작은 후보 숫자를 적습니다. 휴대폰을 세로로 들었을 때는 아래쪽 메모 줄을 쓰고, 메모 버튼으로 메모 줄을 숨길 수 있습니다. 가로로 들면 메모 버튼으로 메모 모드를 켜고 끕니다.
  • 후보: 누르면 후보 모드가 켜져 누르는 빈칸마다 들어갈 수 있는 숫자를 채웁니다. 길게 누르면 모든 빈칸을 채웁니다(C / Shift+C).
  • 지우기 Del, 취소 Ctrl+Z, 방향키로 칸 이동.
  • 이미 넣은 숫자를 바꾸려면 먼저 지운 뒤 다시 넣습니다.

힌트

힌트(H)는 지금 판에서 쓸 수 있는 가장 쉬운 기법을 찾아 판 위에 선과 색으로 보여 줍니다. Enter나 숫자 넣기 / 메모에 적용으로 바로 적용할 수 있습니다. 설명에 밑줄 친 칸·행·열 이름에 손가락이나 마우스를 올리면 판에서 그 자리가 밝아집니다. 기법이 무엇인지는 기법 메뉴에서 예시와 함께 볼 수 있습니다.

난이도와 채점

  • 1~5단계는 기법만으로 풀리고, 6~8단계는 가정(이 칸이 이 숫자라면?)이 필요합니다.
  • 즉시 확인: 틀린 숫자를 바로 빨갛게 표시합니다. 기회 3번 또는 무제한.
  • 다 채우고 채점: 판을 다 채운 뒤 한꺼번에 채점합니다.
  • 힌트 횟수(3회 / 무제한)와 채점 방식은 설정에서 바꾸며 새 문제부터 적용됩니다.

같이 하기

  • 방 만들기로 6자리 코드와 링크를 받아 친구에게 보냅니다. 한 방에 최대 4명.
  • 대전: 같은 문제를 동시에 풀고 먼저 완성한 사람이 이깁니다. 상대의 진행률과 실수만 보입니다.
  • 협동: 한 판을 함께 풉니다. 정답 숫자와 힌트는 모두에게 공유되고, 메모는 각자 따로입니다. 힌트 개수는 팀 전체가 나눠 씁니다.
  • 방에 들어가 있는 동안(시작 전 대기 포함) 혼자 풀던 문제의 시간은 멈춰 있습니다.
  • 참가자 이름 옆에 자리 비움(다른 탭·앱을 보거나 1분 넘게 입력 없음), 응답 없음(15초 넘게 신호 없음)이 표시됩니다. 내 연결이 끊기면 방 막대에 연결 끊김 · 다시 연결 중이 보이고 자동으로 다시 접속합니다.
  • 방 게임을 하다가 방을 나가면 혼자 풀 새 문제로 바뀝니다.
  • 방은 마지막 사람이 나갈 때까지 유지됩니다. 같은 코드로 다시 들어오거나, 참가하기의 최근 방 다시 들어가기를 누르세요.

휴대폰

  • 세로로 들면 판 아래에 정답 줄과 메모 줄이, 가로로 들면 판 오른쪽에 숫자판이 놓입니다.
  • 브라우저 메뉴의 홈 화면에 추가를 누르면 앱처럼 전체 화면으로 열립니다.
  • 설정에서 화면 켜짐 유지와 진동을 켜고 끌 수 있습니다(지원하는 기기에서만 보임).

리더보드

  • 기록 = 풀이 시간 + (힌트 + 실수) × 30초. 낮을수록 좋습니다.
  • 혼자: 완성 후 이름을 넣어 등록합니다. 20초 미만 기록은 등록하지 않습니다.
  • 대전: 완성하면 각자의 기록이 자동으로 등록됩니다.
  • 협동: 완성하면 방장이 팀 기록(참가자 이름 모두)을 한 번 자동으로 등록합니다.
  • 난이도마다 사람(협동은 팀)별 최고 기록만 보입니다.
